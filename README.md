> **Climb & Slide** is a vibrant, 100-tile board race game designed with a **Ludo White & Colorful** aesthetic theme. Features animated token glides, chutes (snakes) and ladders, floating emote animations, in-game chat, and private room multiplayer!

---

## ✨ Features

- 🎨 **Ludo White & Colorful Design**: Bright `#F8FAFC` background with rounded board tiles, colorful gradients, and zero dark/neon elements.
- 💬 **In-Game Chat & Quick Emotes**: Send text messages, quick phrases, or animated floating speech bubbles (`✨ 😊 ✨`) over player tokens in real time!
- 🌐 **Private Rooms & Multi-Tab Sync**: Create private rooms with custom codes (`CS-XXXX`), copy invite links, toggle ready states, and play seamlessly.
- ⏸️ **In-Game Controls**: Top-bar Pause/Resume toggle button with board pause overlay and Exit confirmation modal.
- 🟨 **Path Visualizer**: Highlights origin, landed, destination, and event target tiles so move history is crystal clear.
- 🧪 **100% Test Pass**: 37/37 unit & board engine tests passing in Vitest.

## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/AlfiMaulanaA/CnL.git

# Navigate into the project
cd Chutes&Ladders

# Install dependencies
npm install

# Run development server
npm run dev

# Run unit tests
npm test
```
